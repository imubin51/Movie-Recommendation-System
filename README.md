Movie Recommendation System in KNIME Analytics Platform

The rapid growth of digital content platforms has made recommendation systems an essential component of modern information systems. With thousands of movies available to users, recommendation systems help reduce information overload by suggesting content that aligns with individual user preferences. This project focuses on the design, implementation, evaluation, and visualization of a movie recommendation system developed using the KNIME Analytics Platform.
The primary objective of this project was to build an accurate and interpretable recommendation system using a movie dataset, test and refine the model, and finally present the results through an interactive Microsoft Power BI dashboard. The project combines theoretical concepts covered during the course with practical data analytics, workflows, and visualization.
